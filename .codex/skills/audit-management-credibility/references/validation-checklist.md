# Management Credibility Audit - Validation Checklist

Binary pass/fail criteria for validating output quality.

---

## Data Sources (Section 1 - REQUIRED)

- [ ] Data Sources table present AS FIRST SECTION of Analysis
- [ ] Table includes columns: Source, Count, Date Range, Coverage
- [ ] Transcripts: Count shown (e.g., "20 of 20") with date range
- [ ] Quarter count mathematically correct (e.g., FY2021-FY2025 through Q2 = 18 quarters, not 20)
- [ ] **Explicit quarter calculation shown:** Document includes step-by-step math (e.g., "4 + 4 + 4 + 4 + 1 = 17")
- [ ] **Header/Appendix consistency:** Quarter count in header matches Appendix transcript count exactly
- [ ] **Appendix completeness:** Every quarter in the stated range has a corresponding row in the Appendix table
- [ ] Web Research row present (for insider/compensation data)
- [ ] Data gaps explicitly documented (or "None — full coverage")

---

## Quantitative Scorecard (Section 3 - REQUIRED - 3 Tables)

- [ ] **Table 1: Promise Delivery Summary** present with columns: Category, Promises Made, Scored, Hit Rate, Avg Score
- [ ] At least 5 promise categories tracked (Financial, Capital Allocation, Operational, Cost/Efficiency, Strategic)
- [ ] Total row included
- [ ] **Table 2: Trend Over Time** present showing year-by-year hit rate and avg score
- [ ] Each year of audit period represented
- [ ] Notable Events column included
- [ ] Trend statement present (Improving/Stable/Declining with explanation)
- [ ] **Table 3: Guidance Accuracy** present with columns: Metric Type, Times Guided, Beat, Met, Missed, Accuracy
- [ ] Metric types include: Expense, Revenue, Margin, EPS, Other (or "Not Provided" with explanation)
- [ ] Guidance style explicitly stated (Conservative/Accurate/Optimistic/Variable)

---

## Say/Do Matrix

- [ ] Visual ASCII matrix diagram present
- [ ] Company placement clearly marked on matrix
- [ ] Quadrant name stated (Credible Consistent / Underpromise Overdeliver / Overpromise Underdeliver / Empty Suits)
- [ ] Rationale provided (2-3 sentences with evidence)
- [ ] Investment implication stated

---

## Key Management Quotes

- [ ] At least 5 verbatim quotes included
- [ ] Each quote has speaker attribution (name, title, quarter)
- [ ] "Commitments Delivered" section with quotes and outcomes
- [ ] "Commitments Missed" section with quotes and outcomes (or explicit statement that none exist)

---

## Missed & Partial Promises

- [ ] Dedicated section present (even if no misses found)
- [ ] Table format with columns: Date, Original Promise (verbatim), What Happened, Management Response, Score
- [ ] Analysis paragraph covering: total misses/partial count, pattern in misses, how management handles failure
- [ ] If no misses: explicit statement "No promises scored below +1 — verify scoring rigor"

---

## Promise-by-Promise Detail

- [ ] Financial Targets table present
- [ ] Capital Allocation table present
- [ ] Operational Goals table present
- [ ] Cost/Efficiency Programs table present (formal programs only)
- [ ] Strategic Initiatives table present
- [ ] Each table includes: Date, Promise (verbatim quote), Source, Specificity, Timeframe, Outcome, Score
- [ ] Specificity ratings consistent (Specific = has number/date/target; Directional = has direction without number; Vague promises excluded)
- [ ] Cost/Efficiency Programs: Only formal programs with names/targets/timelines included in table (NOT informal "N/A" rows)
- [ ] Cost/Efficiency Programs: "Restructuring Cost" column contains dollar amounts or "Not disclosed" (not "N/A")
- [ ] Cost/Efficiency Programs: "Actual Savings" column contains dollar amounts, estimates with source, or "Not disclosed — [reason]"
- [ ] Cost/Efficiency Programs: If company has no formal programs, explicit statement explaining business model focus (not empty table with N/A rows)
- [ ] Cost/Efficiency Programs: Informal initiatives documented in note after table, NOT as table rows

---

## Pattern Analysis

- [ ] Positive Patterns section with specific evidence
- [ ] Concerning Patterns section with specific evidence
- [ ] Kitchen Sink Analysis: either identified quarters with table OR explicit "None identified"

---

## Capital Allocation Track Record

- [ ] M&A Synergy Tracking table (if acquisitions during period)
- [ ] Buyback Timing Analysis table OR statement explaining limited data
- [ ] Other Capital Allocation decisions documented
- [ ] Capital Allocation rating stated (Excellent/Good/Mixed/Poor)

---

## Insider Ownership & Compensation

- [ ] Executive Ownership table present with columns: Executive, Title, Base Salary, Shares Owned, Value, % of Company, Multiple of Salary
- [ ] **Minimum 3 executives:** CEO, CFO, plus at least one additional executive (segment president, COO) OR explicit note that additional data unavailable
- [ ] Key business unit executives who speak on earnings calls are included (or explanation why data unavailable)
- [ ] Base salary included for each executive (required to verify "Multiple of Salary" calculation)
- [ ] Ownership data source cited with page number (e.g., "Source: FY2024 Proxy Statement (DEF 14A), pages 42-45")
- [ ] Source citation is from actual proxy document (NOT aggregator sites like TipRanks, GuruFocus)
- [ ] If page number unavailable due to PDF access issues, explicit statement included: "page reference unavailable due to PDF access; verify via EDGAR"
- [ ] Executive transitions during audit period noted in ownership section header (e.g., "*Note: CEO transition announced December 2025...*")
- [ ] If CEO/CFO changed during audit, impact on promise accountability documented
- [ ] Recent Insider Transactions table OR statement that data is limited
- [ ] Compensation Structure table with % breakdown by component
- [ ] CEO total compensation stated
- [ ] Compensation vs performance comparison (pay growth vs stock vs EPS)
- [ ] Alignment assessment stated (Aligned/Mixed/Misaligned)
- [ ] Overall Alignment Score table with factor-by-factor scores

---

## Non-GAAP Definition Drift

- [ ] Table comparing Year 1 vs Year 5 adjustments for key metrics
- [ ] GAAP vs Non-GAAP gap table showing trend over years
- [ ] Assessment paragraph stating whether gap is widening

---

## Red Flags

- [ ] Red Flags table with columns: Red Flag, Severity, Evidence, Implication
- [ ] Summary statement (clean / some concerns / significant issues)

---

## Deep Dive: Key Issues (Section 13 - REQUIRED)

- [ ] Section present with header "Deep Dive: Key Issues"
- [ ] If issues exist: structured analysis with What promised, Context, What happened, Management explanation, Pattern, Implication
- [ ] If no issues: Explicit statement "No issues warranting deep dive" with brief justification
- [ ] Section is NOT omitted even if no issues found

---

## Conclusion

- [ ] Credibility Rating stated (HIGH / MODERATE / LOW / CONCERNING)
- [ ] Rating criteria explained
- [ ] "Can you trust guidance?" explicitly answered
- [ ] Guidance discount recommendation
- [ ] Monitoring Points checklist (3-5 items)

---

## Appendix: Source Documents (Section 15 - REQUIRED)

- [ ] Section present with header "Appendix: Source Documents"
- [ ] **Earnings Transcripts Reviewed** table with columns: Quarter, Date, Source, Notes
- [ ] ALL quarters in audit period listed (e.g., all 20 quarters for 5-year audit)
- [ ] Source column shows FMP or web search
- [ ] Key Press Releases Referenced table (if press releases were used)
- [ ] Section creates verifiable audit trail

---

## Memo Document (7 Required Sections)

- [ ] **Header:** Rating, Matrix Placement, Audit Period, Quarters Reviewed
- [ ] **Key Takeaways:** 5-7 bullets with line breaks between
- [ ] **What You Can Trust:** TABLE format (not prose) with columns: Guidance Type, Track Record, Confidence
- [ ] **What to Discount:** TABLE format (not prose) with columns: Guidance Type, Issue, Recommended Discount
- [ ] **Red Flags to Monitor:** CHECKLIST format (- [ ] items)
- [ ] **Bottom Line:** 2-4 sentences, final verdict
- [ ] **Quick Reference:** TABLE with ALL 5 metrics:
  - [ ] Promise Hit Rate (percentage)
  - [ ] Composite Score (+X.X on -2 to +2 scale)
  - [ ] Guidance Style (Conservative / Accurate / Optimistic)
  - [ ] Capital Allocation (Excellent / Good / Mixed / Poor)
  - [ ] Insider Alignment (Strong / Moderate / Weak)

---

## Data Quality Checks

- [ ] All promise scores use consistent scale (+2 to -2)
- [ ] Hit rate calculation matches scored promises (not total promises)
- [ ] Composite score mathematically consistent with category scores and weights
- [ ] Verbatim quotes actually appear verbatim (not paraphrased)
- [ ] Source attribution matches claimed data sources

---

## Cross-Document Consistency (Analysis vs. Memo)

- [ ] Credibility Rating identical in both documents (HIGH / MODERATE / LOW / CONCERNING)
- [ ] Say/Do Matrix placement wording identical in both documents
- [ ] Promise Hit Rate identical in both documents
- [ ] Composite Score identical in both documents
- [ ] If Analysis identifies red flag as unresolved, Memo does NOT claim it is "completed" or "resolved"
- [ ] Quick Reference metrics in Memo match corresponding figures in Analysis
