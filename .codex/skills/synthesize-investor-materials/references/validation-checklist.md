# Pre-Output Validation Checklist

**MANDATORY:** Complete all validation passes before writing the final memo.

---

## A. Event Type & Source Materials

- [ ] Identified event type correctly:
  - [ ] Investor Day (multi-year strategy, TAM/SAM, management showcase)
  - [ ] Capital Markets Day (financial targets, capital allocation, efficiency)
  - [ ] Quarterly Presentation (results vs. expectations, near-term guidance)
  - [ ] Shareholder Letter (philosophy, retrospective, vision)
  - [ ] Standing Overview (periodic deck, not tied to specific event)
- [ ] Read appropriate event-type checklist from `event-type-checklists/[type].md`
- [ ] All source files listed in Source Materials table
- [ ] Each file classified by type (Strategy/Financial/Segment/Overview)
- [ ] Slide counts recorded

---

## B. YAML Frontmatter Complete

- [ ] Basic metadata: company, ticker, event_type, event_date, event_name, synthesis_date
- [ ] Files analyzed count matches Source Materials table
- [ ] Key metrics populated (if presented in materials)
- [ ] Capital allocation populated (if discussed)
- [ ] Quality ratings set: new_information, specificity, event_significance

---

## C. Key Takeaways Quality

- [ ] 5-7 bullets provided
- [ ] Each bullet has **bold lead-in** followed by colon
- [ ] Each bullet contains insight + data point (not just restating facts)
- [ ] Most important insights are first
- [ ] Slide references included for key claims

---

## D. Promise Extraction (Minimum 3)

For each promise captured:
- [ ] **Verbatim quote** — exact words, not paraphrase
- [ ] **Source reference** — slide number
- [ ] **Timeline** — when should this be verifiable
- [ ] **Category** — Financial / Operational / Strategic / Capital Allocation

**Quality check:**
- [ ] Searched CEO presentation for forward commitments
- [ ] Searched CFO presentation for financial targets
- [ ] If <3 promises, stated: "Limited specific commitments — event was primarily [informational/retrospective]"

---

## E. Claims Verification Assessment

For each competitive claim:
- [ ] **Verbatim quote** — exact words
- [ ] **Source reference** — slide number
- [ ] **Verifiability rating assigned:**
  - Strong = public data available
  - Moderate = requires research
  - Weak = no clear verification path
- [ ] **How to verify** — specific data source

**Quality check:**
- [ ] Market share claims captured
- [ ] Industry ranking claims captured
- [ ] Technology/leadership claims captured

---

## F. Guidance Table Complete

- [ ] All revenue/earnings guidance captured
- [ ] All margin targets captured
- [ ] All capital return guidance captured
- [ ] Each row has: Metric, Target, Timeline, Specificity rating, Source
- [ ] Specificity ratings accurate:
  - High = explicit number with timeline
  - Medium = range or directional
  - Low = qualitative only

**Non-Operating Income Check:**
- [ ] Searched for material non-operating income (equity method, investment income, JV income)
- [ ] If >$100M combined, captured in "Non-Operating Income" subsection
- [ ] If none material, can omit subsection

---

## G. New vs. Known Assessment

- [ ] New vs. Known table completed
- [ ] Identified genuinely NEW information (not just restatements)
- [ ] Quality rating `new_information` reflects actual assessment:
  - High = significant new guidance or strategy shifts
  - Medium = some updates mixed with repetition
  - Low = mostly restatement

---

## H. Red Flags & Concerns

- [ ] 2-4 prose bullets on concerns (if any)
- [ ] Each concern has evidence and severity assessment
- [ ] Unanswered Questions list completed (3-5 items)
- [ ] Each question explains why it matters

---

## I. Investment Implications

- [ ] Current Holders section addresses:
  - Does this change the thesis?
  - What to monitor going forward?
- [ ] Prospective Investors section addresses:
  - Entry timing considerations
  - Key risks to understand

---

## J. Editorial Language Check

- [ ] Key Takeaways use source language, not interpretive upgrades
- [ ] No "inflection point" or similar unless management used that phrase
- [ ] Claims use verbatim quotes, not paraphrased stronger versions
- [ ] Red flags are factual observations, not speculation

---

## Validation Complete

All passes completed:
- [ ] A — Event type identified, sources verified
- [ ] B — YAML frontmatter complete
- [ ] C — Key Takeaways quality verified
- [ ] D — Promises extracted (min 3)
- [ ] E — Claims assessed for verifiability
- [ ] F — Guidance table complete
- [ ] G — New vs. Known assessed
- [ ] H — Red flags identified
- [ ] I — Investment implications completed
- [ ] J — Editorial language checked

**Ready to write final memo.**
