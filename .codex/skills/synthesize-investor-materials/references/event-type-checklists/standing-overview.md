# Standing Overview — Event Checklist

**Event Characteristics:**
- Monthly or quarterly investor deck (not tied to specific event)
- Company overview updated with latest data
- Not an earnings presentation (no beat/miss analysis)
- Typically 15-30 slides
- Used for ongoing investor communications

**Primary Focus:** Company positioning, recent performance, strategic initiatives

---

## Mandatory Extraction

### Company Overview

- [ ] **Business model summary** — what they do, how they make money
- [ ] **Key competitive advantages** — stated moats/differentiators
- [ ] **Market position claims** — rankings, market share
- [ ] **Product/service portfolio** — offerings by segment

### Recent Performance

- [ ] **Latest financial results** — revenue, operating income, net income
- [ ] **Key operating metrics** — industry-specific KPIs
- [ ] **YoY comparisons** — growth rates, margin changes
- [ ] **Trailing metrics** — TTM or most recent quarter

### Strategic Initiatives

- [ ] **Current priorities** — what management is focused on
- [ ] **Growth initiatives** — new products, markets, partnerships
- [ ] **Technology investments** — platform, infrastructure
- [ ] **Partnership announcements** — recent or ongoing

### Capital Allocation

- [ ] **Dividend policy** — current yield, growth history
- [ ] **Buyback program** — authorization, deployment
- [ ] **M&A posture** — appetite, recent activity
- [ ] **Cash position** — liquidity

### Forward-Looking Items

- [ ] **Guidance** — if any provided (often limited in standing decks)
- [ ] **Upcoming milestones** — product launches, initiatives
- [ ] **Industry tailwinds** — secular trends management highlights

---

## Red Flag Triggers

Watch for and flag if present:

- [ ] Metrics that stopped being reported vs. prior version
- [ ] Vague language replacing previously specific claims
- [ ] Missing updates on prior commitments
- [ ] Stale data (deck not recently updated)
- [ ] Inconsistencies with recent earnings releases

---

## Quality Signals

Positive signs to note:

- [ ] Consistent format allowing period-over-period comparison
- [ ] Specific metrics with clear definitions
- [ ] Recent data (within current quarter)
- [ ] Balanced view (not purely promotional)

---

## Context Questions

Answer these in the synthesis:

1. When was this deck last updated? Is the data current?
2. What's new vs. the prior version (if known)?
3. What important context is missing (e.g., competitive landscape, risks)?
4. Is this deck promotional or informational?

---

## Event Significance Assessment

**IMPORTANT: Default to `event_significance: low`**

Standing overview decks are typically **LOW** significance. Only upgrade to "medium" if:
- Contains NEW guidance not previously disclosed (not just restated targets)
- Announces NEW strategic initiative (not updates on known initiatives)
- Key metrics significantly changed vs. prior version

Most standing overviews are routine updates → use `event_significance: low`.

---

## Expectations Adjustment

**This is NOT a quarterly earnings presentation.**

Do NOT apply quarterly-presentation standards:
- No "results vs. expectations" analysis required
- No "beat/miss" assessment
- No trend tracking table required
- No Q&A analysis expected

Focus instead on:
- What company is communicating to investors
- Strategic messaging and positioning
- Forward-looking commitments (promises to track)
- Competitive claims to verify
