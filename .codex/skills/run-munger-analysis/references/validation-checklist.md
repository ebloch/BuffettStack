# Validation Checklist: run-munger-analysis

Use this checklist to verify staged processing quality before finalizing the memo.

---

## CRITICAL VALIDATION (Check First)

These items MUST pass. If any fail, the staged processing value is lost.

### Cross-Reference Discipline

- [ ] **Stage 2 addressed ALL Stage 1 flags** — Each flag marked ✓ Validated or ✗ Challenged with evidence
- [ ] **Stage 3 addressed ALL Stage 2 flags** — Each flag marked ✓ Validated or ✗ Challenged with evidence
- [ ] **No flags skipped or marked "TBD"** — Every flag has a definitive resolution
- [ ] **Challenged items have explanations** — If ✗ Challenged, what did the new evidence reveal?

### Scoring Rigor

- [ ] **Every +2 score has "Why Not Higher?" = "N/A"** — If substantive concerns exist, score should be +1
- [ ] **Every +1 or lower has substantive "Why Not Higher?"** — Not just "minor concerns" but specific issues
- [ ] **No +2 for single-source moats** — Wide & Widening requires multiple reinforcing advantages
- [ ] **No +2 for management with any credibility gaps** — Even 85% delivery rate has misses

### Tensions Handling

- [ ] **Tensions Registry populated in Working Analysis v3** — All cross-stage contradictions logged
- [ ] **Each tension marked Resolved or Unresolved** — No blank status
- [ ] **Unresolved tensions reflected in Holistic Adjustment** — If tensions remain, adjustment should be -1 or -2

## EXCEPTIONAL Calibration Check

If the verdict is EXCEPTIONAL (+9 to +12), verify:

### Required (must pass)
- [ ] **Score is +9 to +12** — Mathematical qualification
- [ ] **ALL +2 scores have "Why Not Higher?" = "N/A"** — No substantive concerns in +2 categories
- [ ] **Holistic Adjustment is 0** — No cross-cutting concerns
- [ ] **No unresolved tensions** — All contradictions resolved

### Advisory (gut check, not mandatory)
- [ ] **Gut check is confident "Yes"** — No hedging
- [ ] **Compared to benchmark EXCEPTIONAL companies** — Does it truly belong? (e.g., Visa, Moody's, MSCI)

### Score Composition Guidance

EXCEPTIONAL can be achieved through different score compositions:

| Composition | Score | Valid? |
|-------------|-------|--------|
| Six +2s | 12/12 | Yes — rare but possible |
| Five +2s, one +1 | 11/12 | Yes |
| Four +2s, two +1s | 10/12 | Yes — still EXCEPTIONAL |
| Three +2s, three +1s | 9/12 | Yes — minimum for EXCEPTIONAL |
| Two +2s, four +1s | 8/12 | No — STRONG, not EXCEPTIONAL |

**Key principle:** A company with 4 categories at +2 and 2 at +1 (scoring 10/12) is legitimately EXCEPTIONAL if the +1 scores have substantive "Why Not Higher?" reasoning. The +1 scores reflect honest acknowledgment of limitations (e.g., volume volatility for Predictability) rather than score inflation.

**If +2 gate was enforced rigorously and score is +9 to +12, the verdict is EXCEPTIONAL.** The score range is authoritative; gut check is advisory.
