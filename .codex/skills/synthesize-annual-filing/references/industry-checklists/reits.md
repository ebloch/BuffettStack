# REITs — Mandatory Checklist

**CRITICAL:** Every item must be addressed (found and included, OR explicitly noted as "not disclosed").

## YAML Frontmatter (Required Fields)

- [ ] `metrics.ffo_m`
- [ ] `metrics.affo_m`
- [ ] `metrics.occupancy_pct`
- [ ] `metrics.same_store_growth_pct` (revenue or NOI growth, specify which)
- [ ] `metrics.walt_years` (weighted average lease term)

## Key Metrics

- [ ] FFO and AFFO (NOT GAAP net income)
- [ ] Same-store NOI or revenue growth (specify which is disclosed)
- [ ] Occupancy rate
- [ ] Rent spreads (new vs. renewal if disclosed, or overall recapture rate)
- [ ] **Lease expiration schedule (REQUIRED TABLE)** — must include table showing % of rent or ABR expiring by year for at least next 5 years
- [ ] Cap rates (acquisitions, implied if calculable)
- [ ] Debt maturity profile
- [ ] Dividend payout ratio (as % of FFO/AFFO)

## REIT-Specific Output Adjustments

- [ ] **ROIC suppressed** — Do NOT include ROIC in P&L table (not meaningful for REITs due to GAAP depreciation distortions). Add footnote: "ROIC: Not calculated — REIT accounting makes this metric non-comparable; use FFO/AFFO metrics instead."
- [ ] **Operating margin de-emphasized** — GAAP operating margin affected by D&A; note this in footnote if included
- [ ] **FFO/AFFO prominently featured** — Should appear in both Key Takeaways and Financial Snapshot; FFO/AFFO per share more important than EPS

## Watch Items (Flag If Moving in Concerning Direction)

- [ ] Occupancy declining
- [ ] Rent spreads turning negative
- [ ] Lease expirations concentrated in near-term
- [ ] Debt maturities approaching without refinancing plan
- [ ] AFFO payout ratio exceeding 100%
- [ ] Cap rates compressing on acquisitions (overpaying)
